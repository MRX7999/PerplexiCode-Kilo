# PerplexiCode (moved)

PerplexiCode is now **PerplexiCode Kilo** — [`MRX7999.perplexicode-kilo`](https://open-vsx.org/extension/MRX7999/perplexicode-kilo).

This package is a one-time migration bridge. It keeps the old extension ID so PerplexiCode Kilo can copy your saved
Perplexity accounts (after you confirm), then you can uninstall it. It contributes no commands or views and makes no
network requests.

Source: https://github.com/MRX7999/PerplexiCode-Kilo
